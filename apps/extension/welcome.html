CUSTODI

You're set up. Now pin CUSTODI.

Think before you trust. Verify before you act.

  1. Pin it to the toolbar

    Click the puzzle-piece icon to the right of the address bar, find CUSTODI and click the pin. Risk badges (! high, ? medium) and the ON badge appear on that icon.

  2. Scan the page you're on

    Open any website → click the CUSTODI icon → This page → Scan this page. CUSTODI checks the address, the visible text and whether the page asks for OTPs, PINs, passwords or card numbers.

  3. Check a message

    Paste an email, SMS or WhatsApp text into the Message tab. You get the verdict, the exact suspicious words and every check CUSTODI ran.

  4. Start and stop Live Observe

    Live Observe tab → pick 15, 30 or 60 minutes → Start and allow the permission Chrome asks for. Each page you view is checked while the timer runs. Press Stop now any time to see the session summary — the permission is handed back automatically.

What CUSTODI can see

  • The current tab — only when you click, or during Live Observe
  • Its address, visible text and form-field types
  • Results are stored only in this browser

What it never does

  • Run in secret or after the timer ends
  • Read what you type, passwords or other apps
  • Send page content anywhere

Updated the code? Run npm run build:extension, then click ↻ on CUSTODI in chrome://extensions. The extension is loaded from apps/extension/dist (the folder with manifest.json).
